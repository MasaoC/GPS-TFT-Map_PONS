# 過去の大会ログ（暗号化）

2024〜2026 年の鳥人間コンテストの飛行ログを、いまの飛行 CSV と同じ列の並びにしたもの。
**公開の許可を得ていないので、暗号化した `.enc` だけを置いている。** パスワードはチームの担当者に聞くこと
（リポジトリ・コミットメッセージ・Issue には書かない）。

| ファイル | 中身 |
|---|---|
| `2024-07-27_0936_fused.csv.enc` | 2024 年。追走ボートの PONS の位置・G/S・航跡だけ（元の G/S はノットだったので m/s に直した） |
| `2025-07-26_1539_fused.csv.enc` | 2025 年。機体の PONS の位置＋姿勢（ロール・ピッチ）・Garmin の高度・対気速度センサー |
| `2026-07-26_0804_fused.csv.enc` | 2026 年。機体の PONS の位置・高度＋補正済みの姿勢・推定した真方位・TAS・風・電圧・衛星数 |

## 年ごとの違い（Re:PONS で見るときの注意）

3 年とも記録した機器・センサー・後処理が違う。**同じ列名でも年によって出どころが違う**ので、年をまたいで比べるときは気をつける。
Re:PONS は大会ログを開くとこの注意を出す（`repons/olddata_open.js` の `OLDDATA_NOTES`。ここを変えたらそちらも直す）。

| | 2024 | 2025 | 2026 |
|---|---|---|---|
| 記録した機器 | **追走ボート**の PONS v3（機体には載せていない） | 機体（白夜）の PONS v5＋Garmin＋電装のログを JST で突き合わせ（1 秒ほどずれ得る） | 機体（陽還）の PONS v6β＋BNO085 の生ログの後処理＋log.txt |
| 間隔 | 1 秒 | 1 秒（姿勢などは 15:42:16〜16:28:31 だけ） | 0.5 秒 |
| 位置・G/S・航跡 | ボートの GNSS（G/S はノット → m/s） | PONS v5 の GNSS（1〜2 秒ごとを補間） | PONS v6β の GNSS |
| 高度 | 無い | Garmin の高度（海抜・0.2 m 刻み） | 機体の気圧の KF 高度（GNSS 高度も別の列に） |
| V/S | 無い | **記録に無く、ビューアが高度の差から計算**（0.2 m 刻みの段で粗い） | 機体のバリオの KF の値そのまま |
| ロール・ピッチ | 無い | **BNO085 使用、加速度エラーあり**。取り付けのずれだけ直した（ロール −8°、ピッチ 8° − 生。動画と同じ） | **BNO085 使用、加速度エラーあり**。後から補正（取り付け＋加速・旋回の見かけの傾き）したが消しきれていない |
| 方位 | 無い | 無い（BNO085 の方位が 45 分で 50° 以上流れる） | 後処理で機体の磁気のずれを除いた真方位（飛行区間だけ） |
| TAS の列 | 無い | **対気速度センサーの実測 × 主翼の影響の補正係数**（推定ではない） | **対地速度 − 推定した風**（センサーの実測ではない。平均 6.1〜7.1 m/s に合わせて解いた。動画には電装の対気速度センサー値含む） |
| 風 | 無い | 無い | 後処理の推定（3 m/s 以下に制約、「吹いていく向き」、飛行区間だけ） |
| 地図の北パイロン | （2026 年以降の位置。2024 年のルールの座標は未確認） | **2026 年以降と違う**: 2025 年は南西へ約 1.8 km（35.368138, 136.174102。プラットホームからの方位 318°、2026 年以降は 328°） | 地図と同じ（公式ルール 2026.06.21） |
| Est.Beta（横滑り角） | 無い | 出さない（方位が無いので） | **動画と同じ `beta_air`**（対気ベクトルの向き − 真方位。後処理。CSV の末尾の `beta_air` 列） |
| 電圧・衛星数 | 無い | 無い | log.txt から（60 秒ごと・約 10 秒ごと） |

## 開き方

**Re:PONS から直接**: 公開ページ（https://masaoc.github.io/GPS-TFT-Map_PONS/tools/repons/）の
「🔒 大会ログ」から選んでパスワードを入れる。手元で開いたビューアなら「📁 CSV / log.txt を開く」かドロップで `.enc` を渡す。
復号はブラウザの中だけで行い、パスワードはそのページを開いている間しか覚えない。

**ファイルに戻す**:

```sh
pip3 install cryptography                     # 初回だけ
python3 tools/olddata_crypt.py decrypt        # パスワードを聞かれる。同じフォルダに .csv ができる（git には入らない）
```

できた `.csv` は Re:PONS（`tools/repons/index.html`）でそのまま開ける。

## 大会動画（YouTube 限定公開）

ログに対応する動画の URL も公開できないので、同じパスワードで `videos.json.enc` に暗号化して置く。
Re:PONS でログを開くと一緒に復号し、動画を小窓に出してビューアの再生（再生・一時停止・シーク・速度）に合わせて動かす。
ビューアが止まっているときに動画を動かすと、ビューアがそちらへ合わせる。
小窓は見出しをつかんで好きな場所へ動かせ、下の左右の角で幅を変えられる（このブラウザに覚える。見出しのダブルクリックで右下に戻す）。

平文の `videos.json` はリポジトリの外で作る（`tools/olddata/` に置いても `tools/.gitignore` で入らない）:

```json
{
  "2026-07-26_0804_fused.csv": { "url": "https://youtu.be/xxxxxxxxxxx", "sync": { "video_sec": 0, "jst": "08:20:40.0" } },
  "2025-07-26_1539_fused.csv": { "url": "https://youtu.be/xxxxxxxxxxx" },
  "2024-07-27_0936_fused.csv": { "url": "https://youtu.be/xxxxxxxxxxx" }
}
```

- `sync` は「動画の `video_sec` 秒目が JST の `jst`」。分からなければ書かずに、ビューアで動画とログを同じ場面にして
  「⇆ ここで同期」を押し、±0.5s / ±5s で詰める。合わせた値はそのブラウザに覚え（`videos.json` の `sync` より優先。「↺」で消して戻す）、小窓の下に `videos.json` に書き写す形で出る。
- 暗号化: `python3 tools/olddata_crypt.py encrypt <どこか>/videos.json`（ログと同じパスワードにする。一覧の manifest.json も作り直す）
- 埋め込みは YouTube Studio で「埋め込みを許可」になっている必要がある。手元の HTML（file://）として開いたビューアでは
  YouTube に断られることがあるので、公開ページか http で開く（だめなときは小窓の「YouTube」で別のタブに開ける）。

## 作り方・注意

- 元データからの変換: 2026 年は `tools/fuse_attitude_csv.py`、2024・2025 年は `tools/convert_old_contest_csv.py`
  （元データは `~/Documents/Arduino/GPS_TFT_map/tools/olddata/` にあり、リポジトリには入れていない）。
  列の決め方（2025 年のピッチの符号反転・ロールの取り付けのずれ、2026 年の風向を「吹いていく向き」に直したこと など）は各スクリプトの頭に書いてある。
- 暗号化: `python3 tools/olddata_crypt.py encrypt <csv>...`（PBKDF2-HMAC-SHA256 100 万回 + AES-256-GCM。どちらもブラウザの WebCrypto にあるので Re:PONS が開ける。パスワードは 12 文字以上が必須）。暗号化すると一覧の `manifest.json` も作り直す。
  **このリポジトリは公開なので、守りはパスワードの長さだけ。** 一度 push したものは履歴から消せないので、
  弱いパスワードで暗号化したものを push しないこと。
