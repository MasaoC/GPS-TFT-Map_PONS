人力飛行機のパイロットが使いやすいことを目標とした航法装置です。琵琶湖の鳥人間コンテストに特化しています。  
GPS/GNSS navigation for human-powered aircraft, specialized for the Japan International Birdman Rally at Lake Biwa, Japan.

* **本ブランチ（`PONSv7.1`）は 2027・2028 年大会向け v7.1 基板専用です。**  
  姿勢センサーを Murata SCH16T-K01（外付け FPC）とし、電源回路の安全対策（Q3/Q4/F1/U10）を施した最新設計です。  
  BNO085 搭載の初代 v7 基板用は [`PONSv7`](https://github.com/MasaoC/GPS-TFT-Map_PONS/tree/PONSv7) ブランチを参照してください。
* **v3〜v6 ブランチが実際にフライト利用した実績のある安定版です。**

## PONS を導入するメリット

**飛んでいる間の「道具」であり、飛んだあとの「計測器」でもあります。** 当日の誘導と、次期機体の設計の両方に活用できます。

### 鳥人間コンテストに特化している点
* **パイロット中心設計**: 直射日光下（1000ニト高輝度 TFT）や騒音・ペダリング負荷のなかでも、画面を注視せず音声警報だけでコースやバンク角を把握可能。
* **Auto 10km 自動誘導**: プラットホーム離脱から 10km 折り返し、帰還までを距離判定で自動認識・案内（→ [大会本番での使い方](#大会本番での使い方auto-10km-モード)）。
* **機上風向・風速推定**: 対気速度センサー不要で、ピッチ角と対地速度から機上で風向・風速ベクトルをリアルタイム推定（→ [風の推定](#風の推定)）。
* **PONS Link（機体⇄ボート テレメトリ）**: 920MHz 帯 LoRa により、ボート側の受信機へ機体の航法画面・風情報・警報音をリアルタイムで完全ミラーリング（→ [PONS Link](#pons-link機体ボート-テレメトリ無線)）。

### 次期機体の設計へのフィードバック
SD カードのログを付属ツール（`tools/`）で解析し、機体特性の定量評価が可能です。
* **縦の癖**: フゴイド周期の同定、対気速度の分散推定、巡航余裕度の確認。
* **横の癖**: 上反角・ラダー効果に起因するロール／ヨーの固有周期分析。
* **構造荷重の検証**: 巡航中の鉛直加速度（実測最大 +0.18 / −0.25 G、荷重倍数 1.17 / 0.77）から主桁設計荷重を裏付け。

## 設計と根拠

### 1. 姿勢推定（ESKF: 誤差状態カルマンフィルター）
内蔵フュージョンチップ（BNO085 等）は協調旋回時に比力横成分がゼロになるためロール角を過小評価し、地磁気方位も機体電子機器の影響で 30° 以上狂う課題がありました。  
本システムでは **生のジャイロ・加速度（SCH16T）** と **GNSS 航跡・対地速度** をカルマンフィルター（ESKF）で機上融合しています。
* **初期水平化**: 静止 2 秒間の平均比力から初期ロール・ピッチを決定。
* **初期ヨー注入**: 発進滑走時（対地速度 > 3.0m/s）の最初の航跡（True Track）から真方位を注入（接地中は横滑り角が原理的にゼロのため、航跡＝機首方位）。
* **重力観測（レベリング）**: 準定常直進時（旋回レート小、$\|a\| \approx 1g$）に比力水平成分を 2Hz で観測更新し、GNSS 途絶時でもロール・ピッチの長期ドリフトを防止（実機走行試験で誤差中央値 21.3° → 1.3° に抑制）。

### 2. 風の推定
定常飛行時の揚力平衡式 $L = W = \frac{1}{2}\rho V^2 S C_L$ および揚力傾斜の線形性から、ピッチ角 $\theta$ [deg] から対気速度 $V$ [m/s] を算出します。

$$V(\theta) = V_0 \sqrt{\frac{K}{K + \theta}}$$

* **係数は機体・重量・重心で変わるため、SD カードの `settings.txt` で設定可能**:
  | キー | 意味 | 既定値 | 設定範囲 |
  |---|---|---|---|
  | `airspeed_v0` | $V_0$: ピッチ 0 度での巡航対気速度 [m/s] | 7.00 | 3〜20 |
  | `airspeed_k` | $K$: 揚力がゼロになるピッチまでの角度 [度] | 10.00 | 3〜60 |
  | `airspeed_min` | 推定対気速度の下限 [m/s] | 5.80 | 1〜20 |
  | `airspeed_max` | 推定対気速度の上限 [m/s] | 9.00 | 1〜25 |
* $\text{風ベクトル} = \text{対地速度ベクトル} - \text{対気速度ベクトル}$（対気速度の向き＝機首方位）により算出。
* 旋回中の横滑り角による誤差混入を防ぐため、直進が累計 10 秒以上継続した場合のみ更新。
* `settings.txt` は本体が保存のたびに書き直します（書き込んだコメント行は消えるため、メモは別ファイルに残してください）。

### 3. GNSS の起動を速くする（AssistNow Autonomous）
SAM-M10Q が自律予測した数日先までの衛星軌道をバックアップ電池（MS621FE）で保持することで、前日と同じ時間帯であれば **起動から 3〜4 秒で測位完了** します（通常コールドスタート 23 秒）。

### 4. PONS Link（機体⇄ボート テレメトリ無線）
* 送信機（機体）から受信機（ボート）へ、**形式 2 の 32 バイト固定フレーム** を送信（下り一方向）。
* 電波法適合のため、標準ではローワーバンド（CH0/3/6/9/12、SF8、1Hz）を使用し、混雑時はアッパーバンド（CH15/21/27）へ退避可能。
* 詳細は **[docs/pons_link.md](docs/pons_link.md)** を参照してください。

## 画面仕様と操作

### 画面各部の構成
* **画面上部**: 対地速度 (m/s)、10秒平均ピッチ（`Pavg`。大きい枠）、真方位（`TT`）、速度精度（`sAcc`）。
* **画面中央**: 内蔵ベクタ地図（OSM 由来）、現在位置、航跡（緑線、最大 500 点 / 約 25km。跳躍 300m 以上は線引き除外）、パイロン基準線、コース警報アーク（向かうべき方位への赤線円弧）、旋回指示矢印（コースズレ 15° 以上で点滅）。
* **画面左下**: 風向風速ベクトル矢印（吹いていく方向、色は風速）、風向 3 桁（吹いてくる真方位）、ヨー精度（`Y95`）、瞬時ピッチ（`P`）、ロール（`R`）、自動ロールトリム（`Rtrim`）。
* **画面下部**: JST 時刻、最大対地速度（MAX GS。2 回連続の小さい方のみ採用）、目的地コース（TC）、目的地直線距離（km）、捕捉衛星数（10 以上で緑）、バッテリー残量（充電中 `CHG`、SW OFF 充電 `SW OFF`、無線ミラー中 `s72r85`）。
* **画面最下部**: ナビゲーションモード（`10K AWAY` / `10K INTO` / `FLY INTO` / `FLY AWAY`）、目的地名、SD 認識状態。

### 設定画面
NAV 画面でスイッチ長押しで入ります。
* 各行の右端の丸が設定状態を示します：**緑＝本番推奨**、**赤＝本番不可（デモやリプレイ等）**、**オレンジ＝許容だが既定外**。**本番フライト前に赤丸が無いことを確認してください**。
* 地図拡大率は NAV 画面でボタンの**ダブルクリック**でも変更可能（標準縮尺 scaleindex=3 / 画面幅約 18km で緑）。
* 設定は SD の `settings.txt` に自動保存されますが、**DEMO / REPLAY モードは保存されません**（再起動すれば必ず本番航法へ復帰する安全設計）。
* **本番前チェック（画面右上）**:
  飛ぶ前に確かめる項目が揃うと緑の `READY` となり、地上静止中に 1 度だけ「準備完了」と音声読み上げします。欠けていると赤の `NOT READY` と不足項目が表示されます。
  
  | 表示 | 足りない項目 |
  |---|---|
  | `GNSS` | 3D 測位、`gnssFixOK`、水平位置精度 5m 以内 |
  | `IMU` | SCH16T が応答していない |
  | `ESKF` | 姿勢推定が未収束 |
  | `CALIB` | 較正のやり直しが必要（マウントから外された） |
  | `ATT` | 地上で姿勢が申告値からズレ続けている（地上チェック発報中） |
  | `SET` | 設定画面に赤丸がある（標準縮尺でない、Auto 10km でない等） |
  | `USB` | USB ケーブルが挿さっている |
  | `BATT` | 電池残量 50% 未満、過放電ラッチ中、または電源異常 |
  | `SD` | SD カードが認識できない |
  | `LINK` | 送信モードで無線モジュール無応答、または重複送信機あり |

### IMU / ESKF 画面（点検と較正）
3 ページ構成（短押し＝カーソル移動、長押し＝実行）。
* **1 ページ目（点検手順）**:
  1. `SET PITCH`: 機体の現在ピッチ申告値（-3.5〜+2.0°、0.5° 刻み）。本番プラットホーム（-3.5°）でも申告値に合わせれば正確に水平較正可能。
  2. `SET ROLL`: ロール申告値（通常 0°。ウィングロー保持時のみ使用）。
  3. `APPLY`: ゼロ点較正の実行。ボタンを離してから 1 秒後に実行（ボタン押下による機体揺れを回避）。
  4. `Roll/Pitch/Yaw func`: 姿勢機能の一括 ON/OFF マスタースイッチ。
* **2 ページ目**: 生ジャイロ・加速度と静止判定。
* **3 ページ目**: ESKF 内部診断、ヨー精度、`level offset`（前回 APPLY 日時）。

## 警告音・警報

詳細は **[音仕様 (docs/pons_sound.md)](docs/pons_sound.md)** を参照してください。

* **航路・コース警報**: 15° 以上の針路変化で Chime＋「トラック」、向かうべき方位（TC）からのズレ放置で 4Chime＋「進路、右(左)に旋回」（修正中は停止）。
* **バンク角警告**: ロール絶対値が 4° を 1 秒超えると「バンク！バンク！」音声。
* **待機中姿勢ズレ / 較正警告**: 地上静止中に申告値から 3° ズレが 60 秒継続で警告。日付を跨いだ場合は再較正を促す音声。
* **電源・安全警報**: 電池電圧 3.5V 未満で「バッテリー低下」＋バックライト点滅省電力。過放電（3.0V 未満）ラッチ時は次回 USB 接続時に完全充電禁止ロック。高温充電（45°C 超）時は抜去警告。

## 大会本番での使い方（Auto 10km モード）

1. 目的地を **PLATHOME**、Navigation Mode を **Auto 10km** に設定。
2. プラットホーム上で右上が緑の `READY` となり、「準備完了」が鳴ることを確認。
3. 発進時は自動で `10K AWAY`（往路）となり、プラットホームから離れる最短距離方角へ誘導。
4. プラットホームから 10.475km 離脱すると自動更新音が鳴り `10K INTO`（復路）へ自動反転。目視でパイロン旋回を終えるまではコース警報を無視し、旋回完了後に誘導線へ合流。
5. 復路でプラットホームから 1.5km 以内に入ると再び `10K AWAY` に切り替わり、1km パイロン探索を支援。
* 折り返し状態は SD に保存されるため、飛行中に電源再起動が発生しても直前のモードに正確に復帰します。

## SD カードの構成

```
/
├── settings.txt                  # 設定ファイル（装置が自動更新）
├── mapdata.csv                   # 独自追加地図（KML 変換データ）
├── destinations.csv              # 追加目的地（名前, 緯度, 経度）
├── override_pilon_coordinate.csv # パイロン座標の上書き
├── data/                         # 自機の飛行ログ CSV（2Hz）
├── received/                     # PONS Link で受信した他機ログ CSV
├── imu_replaydata/               # 姿勢（ESKF）ログ（5Hz、リプレイ再現用）
├── imuraw/                       # 生 IMU バイナリログ（62.5Hz）
└── log.txt                       # 起動・診断・通信イベントログ
```

* **飛行 CSV フォーマット (`data/*.csv`)**: 2Hz 記録
  ```csv
  latitude,longitude,gs,TrueTrack,GNSS_Altitude,KF_Altitude,KF_Vspeed,pressure,voltage,numsat,date,time,lux,backlight
  ```
* **目的地の追加 (`destinations.csv`)**: 
  SD カードのルート直下に配置。1 行に `名前,緯度,経度`（例: `KASAOKA03,34.495000,133.495000`）を記述。内蔵 4 件（PLATHOME / N_PILON / S_PILON / TAKESHIMA）の後ろに最大 100 件追加。
* **パイロン座標上書き (`override_pilon_coordinate.csv`)**:
  大会直前に再ビルドなしでパイロン座標を上書き可能（`PLATHOME`, `N_PILON`, `S_PILON`, `PILON_1KM`, `TAKESHIMA`）。設定画面の `Map data detail >` で `COURSE SD OVERRIDE` と表示されていれば適用完了。
* **独自追加地図 (`mapdata.csv`)**:
  Google Earth の KML パスから `tools/kml_to_mapcsv.py` で生成。PATH 名の 1 文字目で線の色を指定可能（`r`=赤 / `o`=橙 / `g`=灰 / `m`=マゼンタ / `c`=シアン / `b`=青）。

## ツール (tools/)

* **[PONS Flight Viewer](tools/flight_viewer/index.html)**: ブラウザ（Chrome / Edge）完結型の WebSerial ログ吸い出し・可視化再生ツール。
  * 風の三角形（Wind Triangle）、人工水平儀・スリップボール、横滑り角推定（$\text{Est.}\beta$）HUD、自機／受信機（ボート）の連携プロットに対応。
* **解析スクリプト**:
  * `tools/logcsv2kml4earth.py` / `logcsv2tourkmz.py`: Google Earth 用 KML / KMZ 変換
  * `tools/createmovie_csv2mp4.py`: 飛行再現 MP4 動画生成
  * `tools/flightanalysis/`: スペクトル解析、フゴイド周期・過負荷 G 評価
* **アセット・ファーム生成**:
  * `tools/vectormap/build_vectormap.py`: OpenStreetMap から内蔵ベクタ地図データを生成
  * `tools/gen_wav_flash.py`: 音声 WAV を FLASH 焼き込み用 C++ データへ変換
* **単体テスト・検証**:
  * `tools/attitude_test/`: PC 上での 250Hz ESKF アルゴリズム検証スイート
  * `tools/sch16t_test/`: Pico 2 を用いた SCH16T-K01 単独 SPI テスト用スケッチ

## 着水（水没）後の処置

1. 電源を即座に OFF にし、外装ケースを開けて水分を完全に拭き取る。
2. バッテリー端子および TFT フレキを取り外し、基板を無水エタノールで洗浄。
3. シリカゲルを入れた密封袋で数日間徹底乾燥（湿度 20% 以下推奨）。
4. GNSS バックアップ電池（MS621FE）およびスライドスイッチは腐食しやすいため点検・交換を推奨。
