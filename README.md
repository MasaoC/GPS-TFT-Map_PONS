# PONS 概要/Abstract
 * 人力飛行機のパイロットが使いやすいことを目標とした航法装置（ナビゲーションシステム）です。琵琶湖上空を飛行するパイロットの支援をしています。Arduinoを使用し、TFTにGNSSマップや位置・速度・方位の情報を表示します。琵琶湖での鳥人間コンテスト用に特化しています。GPS/GNSS navigation for human-powered aircraft specialized for the Japan International Birdman at Biwako, Japan.
 * 3Dプリントケース及び基板データ（KiCad)あり。ケースは、PLA_LWが軽量化でオススメです。
 * PONSデバイスの使い方や画面の見方などの詳細は、docsフォルダに説明書があります。このREADMEファイルの方が情報が古い場合があります。
 * PONS for HPA = Pilot Oriented Navigation System for Human-powered aircraft = 人力飛行機用パイロット向けナビゲーションシステム
 * ソフトウェアは **0.894v5**（Build 20261025）。0.893 に、v6（0.894〜0.949）と v7（0.950〜0.995）の改良のうち
   v5 のハードで動くものを移植したもの。変更点は下の「0.894v5 の変更点（2026-10）」。末尾の `v5` は v6 / v7 の番号と重ならないようにするため。
 * 地図は OpenStreetMap から生成した**ベクタ地図をファームウェアに内蔵**しています（`vectormap_data.cpp`）。SDカードが無くても地図が出ます。
   * 0.893 までの Google map API の bmp 画像を SD カードから読む方式は**廃止**しました（v6 の 0.93 と同じ）。
   * Google earth で作った緯度経度列を `mapdata.csv` として SD に置けば、内蔵地図に**追加**で重ねられます。
 * 日本地図・琵琶湖（沖島・竹生島・多景島）などは、プログラムに事前登録されています。パイロン座標は2026ルールに合わせてありますが、現実のパイロン位置はズレることがあるようです。（2025：600m程度）
 * 大阪大学albatross (2024-2025) にて使用実績があります。

# 0.894v5 の変更点（2026-10）
 0.893 に、v6 の 0.894〜0.949 と、v6 に移した v7 の改良（0.950v6）のうち、v5 のハード
 （Pico 2・Quectel LC86G・スピーカーと音量つまみ・センサー無し・USERLED 無し）で動くものを移した。
 括弧内は v6 / v7 で入った版。

 **故障の見逃し・警報が止まる不具合**
 * **電源経路の異常（充電 IC の故障）を検出する（v7 の 0.993）。** USB 判定（GPIO24）なのに VSYS が 3.9V 未満の状態が 3 秒続いたら、
   地図の下端に赤枠で `POWER FAULT !!` / `UNPLUG THE BATTERY`、電池表示が `PWR!`、30 秒ごとに音声（最低音量 60）。再起動するまで消えない。
   **v5 は充電 IC が電源スイッチの手前なので、スイッチを切っても電池から切れない。電池を外すこと。**
 * **充電中の高温を知らせる（v7 の 0.994 の v5 版）。** USB 接続中に **CPU 温度**が 45°C 以上を 30 秒続けたら
   `TOO HOT TO CHARGE` と音声（60 秒ごと）。42°C 以下で消える。
   * v5 には温度センサーが無いので、マイコン内蔵の温度で見る。CPU 温度は電池の温度ではなく、
     マイコン自身の発熱で周囲より高めに出る（＝早めに警告する側）。目安として使う（v3 の 0.503 と同じ値）。
   * **温度の確かさは `settings.h` の `ADC_VREF_V`（既定 3.3）次第で、1% ずれると約 4°C ずれる。**
     設定画面の下の CPU 温度が室温 +5°C 前後なら合っている。外れていたら、テスターで Pico の 35 番ピン（ADC_VREF）と
     GND の間を測って書き換える（v3 の README と同じ手順）。
 * **電池低下・Auto 10km・コース警報・旋回角速度の判断が地図画面でしか動いていなかった（v6 の 0.963 / 0.965）。** 画面によらず動くようにした。
 * **飛行中の GNSS の断線を検出する（v7 の 0.979）。** 5 秒受信が無ければ地図の上端に `NO GNSS connection !!` の枠と、下降 2 音を 30 秒ごと。戻ると上昇 2 音。
 * **SD まわり（v6 の 0.962 ほか）。** 目的地の壊れた行が (0,0) になる、`settings.txt` を Windows で保存（CRLF）すると設定が既定値に戻る・
   範囲外の値を素通しする、SD の復旧のたびに目的地が増える、起動時に SD を読めないと設定を一度も読まない、
   再生できない CSV を延々と開き直す、測位前のログ時刻が `09:00` になる、を直した。
 * **音（v6 の 0.901〜0.923 と v7 の 0.963〜0.985）。** 優先度付きの待ち行列、音声とトーンの同時再生、10bit の PWM。
   音量 0 の間に電池低下の音声（最低音量 60）が遅れる・後回しになると最低音量を失う、などを直した。
 * **飛行中の再起動で Auto 10km の向きが逆になる問題（v6 の 0.948）。** フェーズを SD に残して起動時に戻す（デモ・リプレイ中は残さない）。

 **音声を本体 Flash に内蔵（v7 の 0.982）**
 * 音声 16 本（約 0.66MB・41 秒）をファームウェアに焼いた。**SD が無くても壊れていても警報が喋る。**
   SD の `wav/` フォルダは不要になった（あっても読まない）。
 * 原本はこのフォルダの `wav/`。差し替えたら `python3 tools/gen_wav_flash.py` で `src/flashdata/wav_data.cpp` を作り直す
   （`--check` で原本と生成物の一致を確かめられる）。8bit / 16kHz / モノラル以外は止まるので、`tools/clean_wav8.py` を通すこと。
 * 起動時に SD が読めないときは、起動音とは別に 500Hz のビープを 10 回鳴らす（v5 には USERLED が無いので、音が唯一の手段）。
 * 起動ロゴ（`logo.bmp`）は SD のまま。

 **ナビ・表示（v6 の 0.9〜0.949）**
 * **方位を真方位にそろえた（v6 の 0.942）。** 0.893 までは磁方位（`MT` / `MC`。真方位に 8 度を足していた）。
   2026 年ルールの TC はプラットホームから北 328° / 南 258°（真方位）。
 * 内蔵ベクタ地図（v6 の 0.93）、TRACK UP の自機を画面の下寄りに、測位状態の印（× / 精度の円）、最大対地速度（5 分と全時間）。
 * 縮尺の変更はダブルクリック。設定画面に Map scale と各項目の状態の丸（v6 の 0.921）。
 * パイロン座標を SD の `override_pilon_coordinate.csv` で上書きできる。西パイロンを南パイロン（`S_PILON`）と呼ぶ（v6 の 0.943）。
 * リプレイ: SD の飛行 CSV を再生（v6 の 0.92 / 0.922）。速度 x1・x2・x20、静止区間を飛ばす、大会データ。
   v5 の 0.893 以前の CSV（`Altitude` 列）も、v6 / v7 の CSV も読める。
 * ナビの丸めの修正（v6 の 0.965）、SD を読めないときの既定値を Auto 10km・TRACK UP（v7 の 0.984）、Auto 10km の折り返しの音を往路と復路でそろえた。
 * **本番前チェック（v7 の 0.994）。** 設定画面の右上に `READY` / `NOT READY` と足りない項目（`GNSS` `SET` `USB` `BATT` `SD`）。
   そろって地上で止まると 1 度だけ「準備完了」。GNSS は 3D 測位・水平精度 5m 以下（GST が来ていなければ HDOP 2.0 以下）。
 * 設定画面を 3 分放置したら地図へ戻る（別れの声ではなく短い降下音）。起動直後にタイトル、`log.txt` に起動ごとの `BOOT` 行。
 * 電圧表示の時定数を呼び出し回数から切った（v7 の 0.989）。

 **GNSS（LC86G）**
 * 測位は **1Hz のまま**（このチップの仕様）。
 * 起動時に PAIR コマンドで出力を設定し、応答（`$PAIR001`）を `log.txt` に 1 行残す（`GPS CFG OK GSA=0 GSV=0 GST=0 EASYon=0`。
   数字は 0=成功 3=非対応 -1=応答なし）。通らなかったとき・途中で再接続したときは、NMEA が届き始めたところで送り直す。
   * **GSA を常に出す**（2D/3D と DOP。0.893 は地図画面で止めていた）。GSV は衛星表示の画面でだけ出す。
   * **GST を出す**（緯度・経度の誤差から水平精度 `hAcc` を作る）。GST が出せないモジュールでは HDOP で代える。
   * **EASY を有効にする**（LC86G が受信した軌道から数日先まで予測する機能。u-blox の AssistNow Autonomous に当たる）。
     基板のバックアップ電池（MS621F）が生きていれば、前日と同じ時間帯の起動が速くなる見込み。`settings.h` の `GNSS_USE_EASY` を 0 で止める。
 * GPS DETAIL 3 に `gnssFixOK`、`hAcc(GST)`、`EASY` の結果を出す。`log.txt` には最初の測位（`GPS FIXED ... after boot`）と 10 秒ごとの精度（`ACC ...`）。
 * 止まっていて RMC の方位が空のときは、前の方位を保つ（そのままだと 0 度＝北として読まれる）。

 **SD カード**
 * `wav/` は不要（音声は本体に内蔵）。`settings.txt` には `upward_mode` と `auto10k_status` が増える（装置が書く）。
 * 飛行 CSV の列: `latitude,longitude,gs,TrueTrack,GNSS_Altitude,hAcc,voltage,numsat,date,time`。

 **v5 に入れていないもの**: 気圧計・IMU を使う機能（バリオ、姿勢推定、バンク角警告、風の推定など）、無線（PONS Link）、
 照度センサーによる自動調光、USERLED の点滅（基板に無い）。

 **実機で確かめてほしいこと**
 * `log.txt` の `GPS CFG` 行がすべて 0 になるか（とくに GST と EASY。非対応なら 3 が出る）。GPS DETAIL 3 の `hAcc(GST)` と `EASY`。
 * USB の抜き差し・非力な USB 電源で `POWER FAULT` が誤検出しないこと。
 * 充電中の CPU 温度（設定画面の下）と、`TOO HOT TO CHARGE` が普段の充電で出ないこと。
 * 音声が SD を抜いても鳴ること、起動時に SD が無いと 10 回ビープが鳴ること。
