# 電源・充電・安全保護回路仕様 (v7.1)

2026-10-15 に発生した充電 IC（MCP73831）焼損事故の分析に基づく、ハードウェア保護回路およびファームウェア安全制御の仕様書です。

---

## 1. 事故原因と恒久対策

### 1.1 事故の機序
v7 送信機において、電源スイッチ投入直後に充電 IC（MCP73831）がラッチアップ発煙。SW を OFF にしても停止せず、電池を抜くまで通電が継続した。
- **根本原因**: スイッチ接点のチャタリング・バウンスによる急峻なサージが、パスコンのない充電 IC の VBAT 端子に印加されてラッチアップ破壊が発生。
- **SW で切れなかった理由**: 充電 IC がスイッチの手前（電池直結）に配置されていたため、破損した IC を介して電池から大電流が流れ続けた。

### 1.2 ハードウェア恒久対策
1. **パスコン追加**: 充電 IC の VDD・VBAT 直近にデータシート推奨の 4.7µF（C37, C40）を最短配置（ラッチアップの根本抑止）。
2. **スイッチ位置変更**: 電源スイッチを手動 FET（Q3）による電子スイッチ化し、充電 IC をスイッチ後段へ配置（SW OFF で充電 IC も完全遮断）。
3. **ポリスイッチ `F1` の選定（0805L050）**:
   - 当初検討した 0805L035 は、夏季の高温環境（40°C）において保持電流が 0.30A まで低下し、充電電流（303mA）と並んで誤トリップする恐れがあった。
   - **0805L050** を採用することで 40°C で 0.40A の保持電流を確保。
4. **充電電流の抑制（303mA / R39 3.3kΩ）**:
   電池 DTP603048(PHR) の最大連続充電レート **0.5C = 430mA** を厳守し、PC の USB 2.0 ポート（500mA 上限）や充電 IC の発熱を考慮して 303mA に設定。
5. **逆接保護 Q4 (AO3401A) & 過電圧保護 U10 (NCP361)**:
   極性反転した電池の誤挿入を完全遮断し、規格外充電器のサージを阻止。
6. **VBUS 分圧抵抗の低インピーダンス化（R34=10kΩ / R35=5.1kΩ）**:
   旧 100k/51k では高温時にショットキーダイオード D3 の逆漏れ電流（約 13µA）で VBUS 測定点が 2V 近くまで浮いて誤報するリスクがあったため、分圧抵抗値を 10 分の 1 に下げて誤検知を防止。

## 2. 電源回路トポロジー (v7.1)

```
[LiPo 電池 860mAh]
       │
       ▼
[逆接保護 Q4 (AO3401A)]
       │
       ▼ (VBAT_IN)
[電源 SW / FET Q3 (AO3401A)] ──(SW OFF 時接点)──▶ GPIO40 を GND に落とす (SW OFF 検出)
       ├────────────────────────────────────────┐
       ▼                                        ▼
[充電 IC MCP73831 (U5)] ◀── [ポリスイッチ F1] ◀── [過電圧保護 U10] ◀── [USB-C]
       │ (充電電流 303mA)                         │
       ▼                                        ▼
[ロードシェアリング Q2 / D3] ──────────────────▶ [VSYS (3.3V DCDC 入力)] ──▶ [TPS63031] ──▶ 3.3V
```

### 電池ラインの 3 個の P-ch FET の役割
| 素子 | 役割 | 省けない理由 |
|---|---|---|
| **Q4** | 電池逆接保護 | 電池逆挿し時にゲートが OFF となり、充電 IC や内部回路への逆電圧印加を阻止 |
| **Q3** | 電源スイッチ | SW4 はゲート接地のみ。スイッチ本体に大電流を通さず、充電 IC 暴走時も SW で切断可能 |
| **Q2** | ロードシェアリング | USB 接続時に電池を負荷（VSYS）から切り離し、外部給電で本体を動かしながら充電 |

### バッテリーパック自体の保護回路仕様（DTP603048(PHR)）
本体基板に加えて、バッテリーパック側にも独立した保護回路基板が内蔵されています。
- 保護 IC / FET: DW01+ / 8205
- 過放電検出 / 復帰: 2.4V ±0.1V（20ms） / 2.8V ±0.1V
- 過充電検出 / 復帰: 4.20V ±0.05V / 4.10V ±0.05V
- 最大連続充放電: 充電 0.5C (430mA) / 放電 1C (860mA)
- ※ 電池を交換・調達する際は、**必ず保護回路付きであることを確認してください**。

## 3. ファームウェアの安全監視仕様

### 3.1 電源経路異常警報 (`power_fault_active()`)
- **条件**: VBUS が 2.0〜4.3V の異常電位に 3 秒継続（正常な USB は 4.4V 以上）。
- **動作**: 画面に `POWER FAULT !! / SW OFF + UNPLUG USB` 赤警告。音声 `power_fault.wav` を 30 秒ごとに発報（最低音量 60）。無線テレメトリへ `LINK_ST_PWR_FAULT` を送信（受信機は 2637Hz ×6 トーン通知）。

### 3.2 SW OFF 充電注意 (`power_sw_off_on_usb()`)
- **条件**: USB 接続中かつ GPIO40（BATPWR）の読みが 1.0V 未満（SW OFF 接点が GND 接続）。
- **理由**: v7.1 では SW OFF だと Q3 のボディダイオード経由の充電となり、満充電電圧より約 0.5V 低い約 3.7V で充電が停止してしまうため。
- **動作**: 地図画面に `POWER SW IS OFF. / TURN ON TO CHARGE` 点滅表示。音声 `charge_sw_off.wav` をセッション中 1 度だけ発報。SW を ON にすると `charge_sw_on.wav`。

### 3.3 高温充電警告 (`power_charge_hot_active()`)
- **条件**: USB 充電中に本体基板温度（MS5611）が 45°C 以上を 30 秒継続（42°C 以下で解除）。
- **動作**: 画面に `TOO HOT TO CHARGE / UNPLUG USB AND COOL DOWN` 赤警告。音声 `charge_hot.wav` を 60 秒ごとに発報（最低音量 60）。

### 3.4 待機中自動減光 (Auto-Dimming)
- **突入条件（すべて満たして 30 秒）**: 輝度スイッチ Low、対地速度 $< 0.30\text{ m/s}$、IMU 静止、照度安定、30 秒無操作。
- **効果**: バックライト Duty を 5% まで絞り、消費電流を 90% 以上削減。
- **即時復帰（0ms）**: 手かざし（照度変動 $\ge 30\%$ かつ $30\text{ lx}$）、助走開始（$\ge 0.60\text{ m/s}$）、ペダリング振動、ボタン操作。復帰後は 30 秒間輝度を維持。

### 3.5 電池低下時の 2 段階省電力
- **第 1 段階 ($\le 3.50\text{V}$)**: バックライト 2 秒点灯 / 4 秒消灯（Duty 33.3%）。音声 `battery_low.wav`（60 秒ごと、最低音量 60）。
- **第 2 段階 ($\le 3.00\text{V}$)**: バックライト 2 秒点灯 / 10 秒消灯（Duty 16.7%）。

### 3.6 過放電（3.0V 未満）ラッチと充電禁止ロック
- **目的**: 3.0V 未満を経験した LiPo 電池は、次回充電時に内部短絡・発火の危険があるため充電を阻止する。
- **誤検知防止ラッチ条件**:
  生 ADC 平均（`s_batt_v`）とピーク追跡（`get_input_voltage()`）の両方が **`[1.80V, 3.00V)` に連続 5 秒間** とどまった場合のみ、内蔵 Flash EEPROM 領域（オフセット 64）へ 1 回だけ不可逆記録。SW 切断過渡や一時的な負荷ドロップでの誤ラッチを完全防止。
- **フライト中の挙動**: 飛行継続を最優先とし、フライト中は新規警告音を発報せず、バックライト第 2 段階省電力のみで電池を使い切るまで航法を継続。
- **次回起動以降の挙動**:
  - **電池単体起動時**: 全画面警告 `DO NOT CHARGE !!` ＋ 音声 `batt_overdischarge.wav`。ボタン長押しで確認解除してナビ画面へ進行可。
  - **USB 接続時**: `UNPLUG USB IMMEDIATELY!` 赤黄点滅の**完全ロック（操作不能）**。30 秒ごとに警告音＋音声を連発。
- **ラッチ解除手順**: SD カードのルートに空ファイル **`batt_unlock.txt`** を置いて起動（検出後に自動削除され通常復帰）。
