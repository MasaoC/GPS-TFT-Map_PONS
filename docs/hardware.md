# PONS v7.1 ハードウェア仕様・自作手順・BOM

このドキュメントは、PONS v7.1 基板の自作・発注・組み立てを行う開発者向けの詳細なハードウェア仕様書です。
部品表（BOM）、推奨品からの差し替え部品の検証事項、JLCPCB への発注手順、手実装および組み立て・導通チェック手順をまとめています。

---

## 1. 基板の構成

v7.1 は 4 枚の基板と、GNSS 用の FPC ケーブル 1 本で構成されています。KiCad のプロジェクトはリポジトリ内の `kicad/` にあります。

| フォルダ | 基板名 | 発注仕様 | 本体との接続 |
|---|---|---|---|
| `mainboard` | 本体 | リジッド 4 層・1.0mm・FR4、PCBA（Economic） | — |
| `GNSSboard_SAM-M10Q` | GNSS（SAM-M10Q） | **リジッド基板（予定）** | 基板の `J1`（Molex 200528-0050）と本体 `J7`（5 ピン）を下の FPC ケーブルで繋ぐ |
| `IMU_murata` | モーションセンサー（SCH16T） | フレキ基板（Flex PCB） | 尾の金端子を本体 `J6`（8 ピン）へ挿す |
| `case_cover` | 照度センサー（VEML7700） | フレキ基板（Flex PCB） | 尾の金端子を本体 `J8`（4 ピン）へ挿す |
| `FPCv71` | GNSS 用 FPC ケーブル（5 ピン） | フレキ基板（Flex PCB）。金端子部は補強板込みで合計 0.3mm | 両端の金端子を本体 `J7` と GNSS 基板 `J1` へ挿す |

* **FPC 一体型設計**: IMU・照度センサーの 2 枚は**基板そのものがフレキ（FPC）**となっており、先端の金端子を本体の FPC コネクタ（Molex 200528）へ直接挿し込みます。
* **GNSS は FPC ケーブルで繋ぐ**: GNSS 基板はフレキをやめてリジッドにする予定です（2026-11-05〜）。フレキ基板は**リフロー前のプリベイク（乾燥）の手間が大きく、リフローそのものも面倒だった**ため、SAM-M10Q をリフローする GNSS 基板だけを分けました。GNSS 基板には本体と同じ FPC コネクタ（Molex 200528-0050）が載っており、`kicad/FPCv71` の 5 ピン FPC ケーブルで本体 `J7` と繋ぎます。ケーブルは両端の金端子が同じ面にあるので、**全体では本体 `J7`-n ↔ GNSS `J1`-(6-n)** になります（ネット上はケーブル `J1`-n ↔ `J2`-n の 1:1）。
* **補強板（Stiffener）**: フレキの 3 枚に裏面の PI（ポリイミド）補強板を 2 か所ずつ貼り付けます。IMU・照度センサーは金端子の部分と部品の実装部分、FPC ケーブルは両端の金端子の部分です。
  * 金端子部分は本体コネクタに適合させるため、基板厚と補強板を合わせて**合計 約 0.3mm** となるよう指定します。
  * 位置と厚さは各基板の補強板レイヤー（注記）に記載されています。

## 2. メーカー推奨部品から差し替えている部品

データシートや公式設計ガイドが**品番指定で推奨している部品**を、入手性等の都合で別品番に差し替えている箇所です。
推奨品で検証された性能から外れる可能性があるため、基板改版や不具合調査時はここを最優先で確認してください。

| 部品 | 対象基板 | 推奨品 | 実際に使っている部品 | 差し替えた理由 | 検証・留意事項 |
|---|---|---|---|---|---|
| RP2350 内蔵レギュレータのインダクタ 3.3µH（`L1`） | v7.1 | Abracon `AOTA-B201610S3R3-101-T`（2016サイズ、極性マーク付き。Raspberry Pi「Hardware design with RP2350」推奨品） | Abracon `AOTA-B252010S3R3MT`（2520サイズ、LCSC `C22416628`） | 推奨品の在庫切れ（2026-10） | 電気特性は同等以上（Isat 2.6A 以上、DCR 110mΩ 以下）。**サイズが異なるためフットプリントが別**。試作で `+1V1` の電圧と GNSS の受信感度（衛星数・C/N0）が v7 と変わらないことを確認 |
| 12MHz 水晶（`Y1`） | v6・v7・v7.1 | Abracon `ABM8-272-T3`（同ガイド推奨品） | YXC `X322512MSB4SI`（20pF、JLC Basic `C9002`） | JLC の Basic 部品で安価なため | **v7.1 の 1 枚で起動時に約 1/20 で固まった**（下の「起動時に固まる件」）。ファームで水晶の立ち上がりを 50ms 待って解消。費用のため当面この水晶のまま（2026-11-06 判断） |

※ v7 の `L1` は推奨品（`AOTA-B201610S3R3-101-T`）のままです。  
※ TPS63031 のインダクタ（Murata `LQH3NP` シリーズ）は TI 推奨品を使用しています。  
※ TPS63031 の VINA・EN・PS/SYNC を束ねて 0.1µF に接続する回路は TI の典型応用回路に準拠しています。

### 起動時に固まる件（v7.1、2026-11-06 に解決）

- **症状**: v7.1 の 1 枚が、電源 ON または SW2 のあと約 1/20 で起動しない。画面は黒、バックライトは
  最大で点いたまま（GPIO34 がリセット時のプルダウンのまま）、USB も無反応。もう 1 枚と v7 では起きない。
- **原因**: 水晶（`Y1`）を起動した直後に、PLL で CPU を 150MHz に上げると落ちる。pico-sdk は水晶の
  STABLE（決まった回数を数えた印。振幅が育ちきった保証ではない）が立つとすぐ PLL を起こすが、
  推奨と違う水晶（CL 20pF・負荷容量 33pF×2）では、まだ不安定なことがある。
  - 起動の見張り（[bootwatch.cpp](../bootwatch.cpp)）の記録では、止まるのは毎回 150MHz に上げた直後
    （段階 41・45 など）。水晶を止めない再起動（watchdog）では 66 回で 0 回、水晶も止める再起動では再現した。
- **対策（ファーム）**: 水晶が STABLE になってから 50ms 待って PLL を起こす（`settings.h` の
  `BOOTWATCH_XOSC_SETTLE_MS`。0 にしないこと）。対策前は水晶を起動し直す約 110 回で 5 回、対策後は 57 回以上で 0 回。
  万一固まっても、起動の見張りの watchdog が約 6 秒で再起動する（log.txt に `BOOT WATCH: restarted by WATCHDOG`）。
- **ハード**: 費用のため当面いまの水晶（33pF×2）のまま。33pF はこの水晶の CL 20pF に合った値なので、
  容量だけ減らすことはしない。推奨回路にするなら `Y1` を `ABM8-272-T3`、`C17`・`C18` を 15pF にする（`R27` 1k は同じ）。
- **原因ではなかったもの**: 電池の経路（Q3/Q4）・TPS63031 の起動（SW2 でも起きる）、RUN の遅延（SW2 の両端に
  1µF を足しても変わらず）、2 枚の実装の差（J6〜J8・スピーカー）、ブート ROM・フラッシュ（止まるのは SDK の起動処理の中）。
- **調べるときの注意**: 固まっていても水晶の 12MHz は出ている（水晶が止まっているわけではない）。RP2350 は SW2（RUN）の
  リセットで RAM も watchdog の記録も消える。watchdog の再起動では水晶が止まらないので、この不具合は再現しない。

### 2026-11-02 より前の回路図で発注した本体基板の改造

初回の基板（2026-11 着）で見つかった問題を、回路図では直してあります。古いデータで作った基板は次の改造が必要です。詳細は [pons_power.md](pons_power.md) §3・§4.1。

| 変更 | 改造のしかた | 直さないと |
|---|---|---|
| `U10` を NCP361SNT1G → **NCP360SNT1G**（LCSC `C603707`） | 載せ替え（ピン配置・フットプリントは同じ） | 電池なしの USB だけ（電池をつないで SW OFF のまま USB も同じ）で起動できない。VSYS が振動し、TFT が点滅し、基板が鳴る |
| `R52` を削除し、`Q4` のゲートを `Q3` のゲートへ | `R52` を外し、Q3 と Q4 のゲート同士を線でつなぐ | SW OFF でも Q3 のボディダイオード経由で、満充電の手前まで中途半端に充電される |
| 充電 LED（`D4` `D6`）と並列に 22µF（`C1`） | `D6` を外し、その場所に 0603 の 47µF を付ける（`D4` だけが光る） | SW OFF＋USB で充電 LED が弱く光り続ける（充電はしていない） |

## 3. 自作の手順

時短と確実性を優先し、JLCPCB にて PCBA（表面実装代行）での発注を強く推奨します（1個あたりの材料費は約2万円）。各自の責任で自作する場合は以下の手順に従ってください。

### Step 1: JLCPCB に基板・PCBA を発注する
KiCad の Fabrication Toolkit プラグイン（JLCPCB Fabrication Tool）を使用すると、各プロジェクトの `production` フォルダに発注用の zip、BOM（部品表）、CPL（部品位置）ファイルが自動生成されます。

* **事前準備（共通）**: 発注データ出力前に、必ず KiCad で「回路図から PCB を更新」して保存してください（PCB 上の BOM 除外・DNP 設定が反映されるため）。
* **`mainboard`（本体）**:
  * **基板仕様**: 4 層、板厚 1.0mm、FR4
  * **PCBA 設定**: Economic、実装面 **Bottom side**、数量 2。表面（Top）は手はんだしやすい部品のみ配置されています。
  * **手実装部品（BOM 除外品）**: `U9`（E220 LoRa）、`J6` `J7` `J8`（FPC コネクタ）、`BT1`（二次電池）、`J1`（スピーカー）、`J4`（SWD デバッグ用）、穴 `H1`〜`H4`。
* **`GNSSboard_SAM-M10Q`**:
  * **基板仕様**: リジッド基板として発注する予定。補強板は無いので、プラグインの `Additional layers` は空のままにします。部品は手実装します。
* **`IMU_murata` / `case_cover` / `FPCv71`（フレキ 3 種）**:
  * **基板仕様**: フレキ基板（Flex PCB）として発注。部品は手実装します（FPC ケーブルは部品なし）。
  * **補強板レイヤー指定**: プラグインの `Additional layers` に補強板レイヤーを**標準名で**指定します（IMU は `User.2`、case_cover は `User.3`、FPCv71 は `User.5`）。独自のレイヤー名（`Stiffeners` 等）を入力するとガーバーから黙って抜けるため注意してください（FPCv71 はレイヤーに `Stiffener` という名前を付けてあるが、指定は `User.5` で、発注 zip に `FPCv71-Stiffener.gbr` が入ることを確認済み）。
  * **外形設定**: 「Set User.2 as alternative Edge-Cut layer」は**オフのまま**にしてください。
  * **発注画面**: 補強板（Stiffener）を PI・裏面で指定。コネクタ挿入部の合計厚が約 0.3mm になるようにします。

### Step 2: 別途購入部品を発注する
「[4. PCBA とは別に発注する部品（手実装用 BOM）](#4-pcba-とは別に発注する部品手実装用-bom)」を参照し、Digikey・マルツ・秋月電子で部品を手配します。

### Step 3: 手実装を行う
* **`mainboard`**:
  * `U9` E220-900T22S(JP) を手実装。アンテナ（TX915-FPC-4510）を IPEX コネクタへ接続。
  * FPC コネクタ 3 個（`J6` 8ピン、`J7` 5ピン、`J8` 4ピン）を実装。
  * GNSS バックアップ電池 `BT1`（MS621FE）を実装（リフロー不可のため手付け）。逆流防止ダイオード `D5` は PCBA 済み。
  * スピーカーを `J1` へはんだ付け。
  * スライドスイッチは PCBA 実装されるため手実装不要です。
* **`GNSSboard_SAM-M10Q`**:
  * SAM-M10Q と 0603 0.1µF（`C2`）を実装（`C3` は未実装）。SAM-M10Q は最初に**リフロー**してください。
  * FPC コネクタ `J1`（Molex 200528-0050）を実装（裏面）。
* **`IMU_murata`**:
  * SCH16T（`IC1`）と `C1`〜`C5`、`R1` を実装。**`R2` は実装しないでください**（CS がプルダウンされて通信できなくなります）。
  * `J1` ピンヘッダは単独テスト（`tools/sch16t_test`）用のため本体組み込み時は不要です。
* **`case_cover`**:
  * VEML7700（`LED1`）と 0.1µF（`C1`）を実装。

### Step 4: ケースの 3D プリント
`case_3Dmodel` フォルダのデータを 3D プリントします（PLA_LW が軽量でおすすめ）。
※ v7.1 専用ケースは作成中。

### Step 5: 電源導通チェック（最重要）
**本体と各基板（GNSS は FPC ケーブル込み）を接続した状態で、テスターで電源・GND の導通を必ず確認してください。**
ピン配列を誤ると SCH16T や SAM-M10Q が破損します。
* **SCH16T**: 本体 `J6` 8番 ↔ IMU 基板 `J3` 1番（+3V3）、本体 `J6` 1番 ↔ IMU 基板 `J3` 8番（GND）が導通すること（本体 `J6` はピン番号が逆順：`J6`-n ↔ `J3`-(9-n)。詳細は [imu_sch16t_bringup.md](imu_sch16t_bringup.md)）。
* **GNSS**: 本体 `J7` 1番（+3V3）↔ GNSS 基板 `J1` 5番（+3.3V）、本体 `J7` 2番 ↔ GNSS 基板 `J1` 4番（GND）が導通すること（FPC ケーブルを挿した状態で）。
* **照度センサー**: 本体 `J8` 1番（+3V3）↔ case_cover `J2` 1番。

### Step 6: 組み込み・配線
1. mainboard にリチウムポリマー電池（860mAh）を接続（**必ず USB を抜いた状態で作業**）。
2. mainboard をプラネジ（M2.5）でケースに固定。
3. IMU・照度センサーのフレキ基板と、GNSS 基板の FPC ケーブルを本体コネクタへ挿入・固定。
4. アンテナをケース側面のカーボン・金属の陰にならない位置に固定。
5. **電源スイッチを ON にして充電を行ってください**（OFF のまま USB 接続しても充電されません。充電 LED も点きません。詳細は [pons_power.md](pons_power.md) §4.1）。
