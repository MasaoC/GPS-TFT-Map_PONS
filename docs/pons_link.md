# PONS Link — 機体⇄ボート テレメトリ無線仕様書

同一ファームウェアの PONS を 3 台製作し、設定により役割を決定します。

| 役割 | 台数 | 設置場所 | 動作概要 |
|---|---|---|---|
| **送信機 (TX)** | 1 | 機体 | パイロット用航法装置。1Hz（アッパーバンドでは約 1.2〜3.5s）でテレメトリを送信 |
| **受信機 (RX)** | 2 | 追走ボート / プラットフォーム | 受信テレメトリにより機体画面を完全ミラー表示。送信は行わない（下り一方向） |
| **予備機** | (1) | プラットフォーム | 機体トラブル時に TX へ切り替えて換装。通常時は RX または OFF |

通信は**下り一方向のみ**であり、受信側から機体への遠隔操作経路は物理的に存在しません（大会レギュレーション適合・安全設計）。

---

## 1. 運用モードとペアリング

- **モード切替**: `settings.txt` の `link_mode`（`OFF` / `TX` / `RX`）。起動時および切替時に音声で読み上げ（`sender_mode.wav` / `receiver_mode.wav` / `link_off.wav`）。
- **グループ ID (`link_group`)**: 他チームとの混信を避ける識別子（0〜255、既定 0）。ペイロード内の ID で識別するためモジュール設定の書き換えは不要。
  - グループ違いは「無信号」と区別して `Signal : GROUP X FOUND` と表示。
  - 受信側での自動スキャンは行わない（待機チャンネルを外すリスクを避けるため）。
- **重複送信機検出 (`DUP SENDER`)**: 同一 CH / SF / Group 内で 2 台の送信機が稼働した場合、`seq` の逆行・停滞を検知して画面に `DUP SENDER !! / 2 TX ON SAME CH/GROUP` 赤ポップアップを表示し、音声で警告（1 分ごと）。2台目を停止すれば 30 秒で自動消去。

## 2. 無線パラメータと電波法適合

モジュールは **E220-900T22S(JP)**（920MHz LoRa、技適取得済、免許不要、送信出力 13dBm / 20mW）を使用します。アンテナは利得 3dBi 以下のもの（推奨: `TX915-FPC-4510` 2dBi）を接続します。

| 項目 | ローワーバンド（標準運用） | アッパーバンド（混雑時退避用） |
|---|---|---|
| **使用チャンネル** | **CH0 / 3 / 6 / 9 / 12**（5 チャンネル） | **CH15 / 21 / 27**（3 チャンネル） |
| **周波数** | 920.8 / 921.4 / 922.0 / 922.6 / 923.2 MHz | 923.8 / 925.0 / 926.2 MHz |
| **帯域幅 (BW)** | 500 kHz | 500 kHz |
| **拡散率 (SF)** | **SF8（既定）**、SF7〜SF11 | SF7〜SF10（**SF11 は選択不可**） |
| **送信間隔** | 1.0 秒固定（休止 50ms） | SF7: 1.0s / SF8: 1.2s / SF9: 2.0s / SF10: 3.5s |
| **電波法制約** | 休止時間 50ms 固定 | 1 回 400ms 以下、送信時間の 10 倍休止、1h 内 360s 以下 |

※ チャンネル間隔は 0.6MHz（アッパーは 1.2MHz）離して帯域の重なりを排除。ただし至近距離では隣接チャンネルでも干渉するため、大会時は事前の調査（Ch scan）を行います。

## 3. 電波上の 32 バイト固定フレーム（形式 2）

電波占有時間と消費電流を最小化するため、空中に送出するフレーム長は **32 バイト固定**（形式 2、`LINK_W2_MAGIC = 0xA2`）です。

| バイト位置 | 内容 |
|---|---|
| **0** | マジックバイト `0xA2` |
| **1** | `seq`（シーケンス番号下 8 ビット） |
| **2** | `group`（グループ ID） |
| **3 - 4** | `status`（送信機健全性フラグ） |
| **5** | `flags`（データ有効ビット: Fix, 速度, 高度, 昇降, 姿勢, 時刻） |
| **6 - 7** | エポック内 0.1 秒時刻（0〜35999） |
| **8 - 15** | 緯度・経度（各 4 バイト符号付き整数、1e-7 度刻み） |
| **16 - 18** | 対地速度 12bit（0.025m/s 単位）＋ 真方位 12bit（0.1° 単位） |
| **19 - 20** | KF 高度（0.1m 単位） |
| **21** | KF 昇降速度（0.05m/s 単位、±6.35m/s 飽和） |
| **22 - 26** | ロール（0.1°）、ピッチ（0.1°）、ヨー（0.1°） |
| **27 - 29** | **回転枠データ**（`seq % 8` により 8 発で 1 周） |
| **30 - 31** | CRC16-CCITT（バイト 0〜29 対象） |

### 回転枠の内容（8 秒周期で低頻度データを循環送信）
- **枠 0**: 年・月・日・時（JST）
- **枠 1**: 10 秒平均ピッチ、ヨー精度（Y95）
- **枠 2**: 自動ロールトリム累積量、推定風速
- **枠 3**: 推定風向（真方位）、GNSS 捕捉衛星数
- **枠 4**: GNSS 生高度、電池電圧
- **枠 5**: 大気圧、地図縮尺（`scale_index`）
- **枠 6**: 水平位置精度（hAcc）、目的地番号
- **枠 7**: ナビゲーションモード、**目的地 ID (`dest_id`)**

受信機側はフレーム受信時に即座に内部構造体 `LinkTelem` へ展開するため、表示・警報・リプレイの処理系は共通化されています。

## 4. ハードウェア結線と E220 制御仕様

マイコン（RP2350B）と E220 は UART1（115200bps 8N1）で直結されます。

| 信号線 | RP2350 ピン | ネット名 | 備考 |
|---|---|---|---|
| UART1 TX | **GPIO8** | `LORA_TX` | E220 RXD へ接続 |
| UART1 RX | **GPIO9** | `LORA_RX` | E220 TXD から受信 |
| AUX 入力 | **GPIO30** | `LORA_AUX` | 状態監視。100nF で GND へバイパス |
| M0 + M1 | **GPIO31** | `LORA_M01` | M0/M1 を 1 本で同時駆動（mode 0 / mode 3） |

### 制御上の重要ルール（破ると静かに壊れる約束）
1. **モード切替後の AUX High 待ち**: モード切替（mode 0 ↔ mode 3）時はモジュール内部のセルフチェックが走り AUX が一時 Low になる。切替後は AUX が High に戻るのを待ち、さらに安定時間（`E220_CFG_SETTLE_MS` 30ms）を待ってから UART 通信を開始すること。
2. **送信パケットの一括 write**: UART 書き込みが途切れると E220 が別パケットに分割発射するため、宛先 3 バイト＋データ 32 バイト（計 35 バイト）を 1 回の `Serial1.write()` でまとめて送信する。
3. **Strict Mode の必須設定**: 環境ノイズレジスタ（`0xA3`）を読むためには、設定レジスタ `0x09` bit6 の Strict Mode が必須（`ensure_strict_mode()` で初回のみ不揮発設定）。
4. **レジスタ書き換え寿命保護**: 設定変更（チャンネル切替等）は RAM 一時書き込みコマンド `0xC2` を使用し、EEPROM 書き込み `0xC0` は初回設定時のみ行う。
5. **環境ノイズ取得書式**: mode 0 のまま `FF FF C1 A3 01` を送信して取得する。mode 3 へ潜って読んではいけない（コマンド解釈が破綻する）。
6. **UART 応答のゴミ読み飛ばし**: モード切替時等に UART FIFO に 1 バイトのゴミが乗る場合があるため、先頭固定長で打ち切らず、応答ヘッダの並びが見つかるまで読み続けること。
7. **モジュール生存確認**: 送信機は 10 秒ごとに環境ノイズ読み出しで応答を確認。3 回連続無応答で `NO RESPONSE` 警告。

## 5. 受信モードの UI と安全制御

### 5.1 ミラー表示中の原則（自機と送信機データの完全分離）
受信モード中は画面上の数値が機体のものに切り替わりますが、**警告や品質表示が自機のまま残る事故**を防ぐため、厳密に分離されています。

| 項目 | ミラー中に参照する対象 | 理由・動作 |
|---|---|---|
| **較正要求（赤字 / Pavg 取消線）** | **送信機の** `LINK_ST_NEEDS_APPLY` | 自機の較正状態は無関係 |
| **`ESKF Not ready`** | **非表示** | 自機の未収束で機体の姿勢表示を消さない |
| **姿勢・風・バンク警報** | **送信機の** `Roll/Pitch/Yaw func` | 受信機自身の ON/OFF に関係なく、送信機の設定で表示・警報 |
| **昇降計（VSI バー・バリオ音）** | **送信機の** V/S | **自機の気圧や IMU で鳴らさない**（ボートの波の揺れで鳴るのを防止） |
| **MAX G/S** | **送信機の** 対地速度 | 自機ボートの最高速を混入させない |
| **GNSS 速度途絶の取消線 / 風の ×** | **送信機の** `LINK_ST_GNSS_LOST` | ボート側のトンネル通過等で機体の表示に線を引かない |
| **地図の縮尺** | **送信機の** `scale_index` に自動追従 | 送信機と同一の視野を共有。ボート側で手動変更された場合は低音 2 連で引き戻す |
| **地上チェック音声** | **送信機の** `LINK_ST_GROUND_*` | 自機ボートの揺れで地上警告を誤発報しない |
| **`NO GNSS connection !!`** | **非表示**（音とログのみ） | 画面の主役は機体のため |
| **`POWER FAULT !!` / `PWR!`** | **自機で判定して表示**（唯一の例外） | 自機ハードの発熱・焼損リスクを警告するため |

### 5.2 電波アイコンと電波強度表示
* **受信機 (RX)**: 携帯電話型のアンテナ本数表示（0〜3 本）。
  - 到達限界 RSSI ＝ 環境雑音（実測 −104dBm）＋ SF ごとの SNR 閾値（SF8 で約 −113dBm）。
  - **余裕 30dB 以上: 3 本（緑）**、**20dB 以上: 2 本（緑）**、**10dB 以上: 1 本（橙）**、**未満: 0 本（橙）**、**無信号: 0 本＋赤×**。
* **送信機 (TX)**: 送信機側は受信できないため、アンテナ本数ではなく**飛行機アイコンから出る電波の弧の脈動（1 秒に 1 回膨らむ）**を表示（測っていないものを見せない設計）。

### 5.3 フェイルセーフと自動同期
* **10 秒電波途絶フェイルセーフ**: 電波途絶が 10 秒継続すると `RECEIVER MODE. NO SIGNAL.` ポップアップを出し、自機航法（自機 GNSS・気圧・バリオ）へ自動復帰。音声「受信が途切れました。自機の情報を表示します」を発報。復帰時は上昇 3 音 ×2。
* **目的地 ID 同期**: 目的地名と座標の CRC16（`dest_id`）により送信機と同期。受信側に同一目的地が存在しない場合は自動で「目的地なし」へ切り替え、誤誘導を防止。
* **リプレイ中・デモ中の無線抑止**: `link_rf_suppressed()` により送信を完全停止（過去ログや仮想機体を「いまの飛行」として電波に流さない安全設計）。

## 6. 送信前チェックとチャンネル調査

### 6.1 送信前チェック（プリフライト）
送信モード（TX）起動時・チャンネル変更時、3 秒間電波を受信して周囲の電波環境を自己診断します。
- `Preflt : OK (-104 dBm)`: 正常（上昇 2 音）。
- `NOISY`: 環境雑音の中央値 $> -100\text{ dBm}$（チャンネル変更を推奨、`link_ch_noisy.wav`）。
- `BUSY`: 雑音の最大値 − 中央値 $> 8\text{ dB}$（他通信のバーストあり、`wireless_busy.wav`）。
- `DUP SENDER`: 同一 Group の PONS テレメトリを受信（重複送信機エラー、赤警告、`link_ch_busy.wav`）。
- `PONS grp n`: 別 Group の PONS を受信。

### 6.2 チャンネル調査 (`Ch scan`)
WIRELESS 画面から実行。全 8 チャンネル（ローワー 5ch ＋ アッパー 3ch）を各 2.5 秒 × 3 周スイープし、最も電波環境が静かなチャンネルを自動選定・表示します。

## 7. 実測性能とアンテナ設置基準

### 7.1 実測データ（到達距離と RSSI）
海辺・平坦コンクリート環境にて **約 350m（SF7）** の安定通信を確認（要求 200m の 1.75 倍）。

| 距離 | RSSI 中央値 | 受信率 | 備考 |
|---|---|---|---|
| 0〜20 m | −60 dBm | 100% | 至近距離 |
| 20〜40 m | −88 dBm | 100% | |
| 40〜80 m | −92 dBm | 98% | |
| 80〜100 m | −102 dBm | 94% | |
| 100〜130 m | −113 dBm | 72% | アンテナ 1 本ライン（限界付近） |
| 130〜145 m | −113 dBm | 24% | パケットドロップ急増 |

### 7.2 アンテナ設置の物理的要件
1. **高さの効果（2 波地面反射）**:
   地上付近では損失が距離の 4 乗で増加。受信電力はアンテナ地上高の積 $(h_1 \times h_2)^2$ に比例するため、**高さ 1m/1m → 2m/2m で +12dB**、**1m/1m → 3m/10m（プラットフォーム上）で +30dB** の絶大なゲインが得られる。
2. **偏波の一致**:
   アンテナを垂直偏波（真上向き）に揃えること。傾き 45° で 3dB、60° で 6dB、80° で 15dB の損失となり、SF 変更（1 段で 2.5dB）以上の差が生じる。
