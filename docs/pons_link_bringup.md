# PONS Link 立ち上げ試験手順 (v7.1)

PONS Link（920MHz LoRa テレメトリ）を v7.1 基板（E220 M0/M1 = GPIO31）で立ち上げ、送受信・電波強度・安全機能を段階的に検証するためのチェックリストです。

- 詳細仕様書 → [docs/pons_link.md](pons_link.md)
- IMU（SCH16T）の立ち上げを先に完了させてください → [docs/imu_sch16t_bringup.md](imu_sch16t_bringup.md)

---

## フェーズ 0：通電前チェック（15 分）

モジュール破損を防ぐため、電源投入前にテスターで導通を確認します。

| # | 確認項目 | 合格基準 | 備考 |
|---|---|---|---|
| 0-1 | E220 の VDD と GND | 数 kΩ 以上（短絡なし） | 電源ライン短絡防止 |
| 0-2 | **VCC（7番ピン）が開放** | 導通なし | **VDD と接続しないこと**（排他利用） |
| 0-3 | M0 と M1 が結線されているか | 導通あり | 1 本の信号線で駆動 |
| 0-4 | M0/M1 が **GPIO31** に接続 | 導通あり | ネット名 `LORA_M01`（**v7 の GPIO41 ではない**） |
| 0-5 | AUX が **GPIO30** に接続 | 導通あり | 状態監視ピン |
| 0-6 | UART ピン交差 | RP TX(GPIO8) → E220 RXD<br>RP RX(GPIO9) ← E220 TXD | 信号方向の確認 |
| 0-7 | アンテナ接続 | IPEX アンテナが接続されていること | **アンテナ未接続での送信禁止**（高周波段破損防止） |

---

## フェーズ 1：モジュール応答確認（1 台・10 分）

1. `link_mode` を **OFF** のまま電源を投入。
2. 設定画面 → `WIRELESS` を開き、`Module` 行を確認。
   - `Module : OK` → 設定の読み書きが一致。通信正常。
   - `Module : NO RESPONSE` → AUX（GPIO30）電位（アイドル時 3.3V）、M0/M1（GPIO31）電位、UART 交差を確認。

---

## フェーズ 2：環境ノイズ測定（1 台・10 分）

1. `link_mode` を **RX** に設定。
2. WIRELESS 画面の `Noise` を確認（正常値: **−100 〜 −110 dBm**）。
3. チャンネルを 0 → 3 → 6 → 9 → 12 と切り替え、最もノイズの低いチャンネルを特定。

---

## フェーズ 2.5：送信前チェック（プリフライト）と安全機能の検証（2 台以上・15 分）

静かなチャンネルを選び、`link_mode` を **TX** に切り替えて 3 秒間のチェック動作を確認します（再実行は WIRELESS 画面の `Preflight: re-run` を長押し）。

1. **正常起動**:
   - 地図に `CHECKING CHANNEL... 3s` が表示され、送信アイコンが橙の弧 1 本になることを確認。
   - 3 秒後に**上昇 2 音**が鳴り、`Preflt : OK (-104 dBm)` となり、`Sent` が 1 秒ごとに増えることを確認。
2. **重複送信機（同一 Group）の検出テスト**:
   - 2 台目を**同一の CH・SF・Group** で TX に設定してから本機を TX に切り替え。
   - `Preflt : DUP SENDER -96dBm` となり、地図に `ANOTHER SENDER / ON THIS CHANNEL !!` が表示され、`link_ch_busy.wav` が鳴ることを確認。
3. **別 Group の PONS 検出テスト**:
   - 2 台目の Group を変えて TX に設定。
   - `Preflt : PONS grp n` となり、DUP SENDER と区別して表示されることを確認。
4. **受信機側での重複送信機検出テスト**:
   - 2 台の送信機を動かした状態で 3 台目を RX に設定。
   - 受信機の地図に `DUP SENDER !! / 2 TX ON SAME CH/GROUP` 赤ポップアップが表示され、音声警告が鳴ることを確認。
   - 送信機 1 台を停止し、**30 秒以内に警告ポップアップが自動消去されること**を確認。

---

## フェーズ 3：2 台間送受信対面テスト（20 分）

机の上で 1〜2m 離して実施。

1. 1 台を **TX**、もう 1 台を **RX**（**CH・SF・Group を完全一致**させる）。
2. **TX 側**: 飛行機アイコン横の電波の弧が 1 秒に 1 回脈動（緑）し、`Sent` が増加すること。
3. **RX 側**: 画面外枠がティール色になり、アンテナが 3 本立つこと。機体側の数値（対地速度・高度・電圧・姿勢）がミラー表示されること。
4. **電波途絶テスト**: TX の電源を OFF にし、**10 秒後** に `RECEIVER MODE. NO SIGNAL.` が表示され、音声「受信が途切れました。自機の情報を表示します」が鳴ることを確認。TX を復旧すると上昇 3 音 ×2 で自動復帰すること。
5. **モジュール脱落保護**: 送信中に E220 モジュールを抜去した場合、30 秒以内に `Module : NO RESPONSE` となり、アイコンに赤×が表示され、Core0（航法地図）がフリーズしないことを確認。
6. **設定変更警告**: WIRELESS 画面で設定を変更して抜けた際、送信機・受信機の双方で「設定が一致していることを確認してください」の音声が鳴ることを確認。

---

## フェーズ 4：受信ログ CSV の確認（10 分）

RX 側の SD カードを取り出し、PC で確認。
- `received/YYYY-MM-DD_HHMM.csv` が生成されていること。
- 列末尾に `rssi, seq, age_ms, roll, pitch, yaw, pitch_avg, roll_trim, yaw_acc95, wind_mps, wind_dir, own_lat, own_lon, dist_m, slot` が揃っていること。
- `seq` が欠番なく 1 ずつ増加していること。

---

## フェーズ 5：屋外・到達距離試験（半日）

見通しの良い平坦地で実施。

1. 送信機・受信機ともにアンテナを**垂直偏波（真上向き）**で設置。
2. 50m おきに離脱し、RX 側の `Signal`（10 秒平均 RSSI）と `Rx/Miss` を記録。
3. **合格基準**:
   - 要求距離 **200m でパケット欠落（Miss）がほぼゼロ** であること。
   - 350m 付近まで受信が継続すること（SF7/SF8）。
4. **SF 選択の基準**:
   - 200m で Miss がほぼゼロなら **既定の SF8 を維持**（SF を上げると送信電流と電波占有率が倍増するため、不要に上げない）。
   - 偏波の傾き（45° で 3dB、60° で 6dB 損失）やアンテナ高さ（地上高を倍にすると受信電力 +12dB）を最優先で改善すること。

## 大会本番前チェックリスト（3 台）

| 項目 | 機体（本番送信機） | 追走ボート（受信機） | プラットフォーム（予備機） |
|---|---|---|---|
| **`link_mode`** | **TX** | **RX** | **RX**（離陸後 OFF） |
| **`link_radio_ch`** | 事前調査した CH | **同一 CH** | **同一 CH** |
| **`link_radio_prof`** | **SF8**（既定） | **同一 SF** | **同一 SF** |
| **`link_group`** | **0 以外の共通 ID** | **同一 Group** | **同一 Group** |
| **起動音声** | 「送信機モード」 | 「受信機モード」 | 「受信機モード」 |
| **起動ログ (`log.txt`)** | `SCH16T init OK` / `MS5611 init OK` / `GNSS CFG OK` の 3 行が揃っていること |
| **電池状態** | 満充電（受信機は +8.2mA 消費のため予備バッテリー確認） |
