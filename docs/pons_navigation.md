# PONS ナビゲーション — 仕様の要約

パイロットに「**いま、どちらへ向かって漕げばよいか**」を 1 つの方位で示すための仕組み。
この文書は**ロジックだけ**を短くまとめたもの。画面写真つきの操作説明は Google Docs の説明書、
しきい値と色の一覧は [../README.md](../README.md) にある。

実装は [../navdata.cpp](../navdata.cpp)（計算）と [../GPS_TFT_map.ino](../GPS_TFT_map.ino)（判断・発報）、
[../display_tft.cpp](../display_tft.cpp)（描画）の 3 つに分かれている。

---

## 1. 前提

- **方位はすべて真方位（True）。** 磁方位は廃止した。機体に磁気コンパスを積まないため。
- 位置は GNSS のみ。**推測航法はしない**（測位が途切れたら最後の位置のまま止まる）。
- **風は一切考慮しない。** 示すのは常に対地の幾何であって、偏流を打ち消す針路ではない。
- 高度はナビゲーションに使わない。すべて水平面の 2 次元で考える。

## 2. 計算の土台

| 量 | 式 | 実装 |
|---|---|---|
| 2 点間の距離 [km] | Haversine（地球半径 6371km の真球） | `calculateDistanceKm()` |
| 2 点間の真方位 [rad] | 球面三角法（`atan2`） | `calculateTrueCourseRad()` |
| 緯度→画面 Y | メルカトル `Y = ln(tan(π/4 + φ/2))` | `latitudeToMercatorY()` |
| 緯度経度→画面 XY | 上記 ＋ 拡大 ＋ 画面上方向への回転 | `latLonToXY()` |

メルカトルは等角なので、**画面上の km/px は東西・南北で等しく `scale / cos(緯度)`** になる。
距離スケールバーも円も同じ係数で描いている。

## 3. 目的地

`extradestinations[]` に登録された地点の 1 つを `currentdestination` で選ぶ。

- 固定の 4 つ … `PLATHOME` / `N_PILON` / `S_PILON` / `TAKESHIMA`
- SD の `destinations.csv` にある分を後ろに追加（最大 100）

座標は `navdata.h` の `#define` が既定値で、SD の `override_pilon_coordinate.csv` があれば
起動時に上書きする。**上書きした値は目的地・地図のアイコン・基準線・センターラインの
すべてが同じ変数を見る**ので、1 か所直せば全部そろって変わる。

## 4. ナビゲーションの出力

毎回の GNSS 更新で `nav_update()` が 2 つだけ更新する。

```
dest_dist … 現在地 → 目的地 の直線距離 [km]
truec     … 現在地 → 目的地 の真方位 [deg]（モードにより 180 度反転）
```

`truec` がすべての表示・警報の入力になる。画面では
フッターの `TC`、地図のマゼンタの誘導線、赤い修正矢印、コース警報の円弧がこれを使う。
測位できていない間は `TC---` / `---km` を出す（内部の位置が (0,0) のため）。

**判断は画面モードによらず動く。** Auto 10km のフェーズ判定・コース警報・旋回角速度は
`loop()` 最上位の `nav_alarm_tick()` にまとめてあり、設定画面や詳細画面を出していても止まらない。
描画だけが地図画面の担当。加えて、**設定画面はボタン操作が 3 分無ければ自動で地図画面へ戻る**
（設定画面を出したまま離陸してしまった場合の保険。`SETTING_IDLE_TIMEOUT_MS`）。

## 5. 3 つのナビモード

設定の `navigation_mode` で選ぶ。

| モード | `truec` | 用途 |
|---|---|---|
| `FLY INTO` | 目的地への方位 | 目的地へ向かう |
| `FLY AWAY` | 目的地への方位 **+180°** | 目的地から最短で離れる |
| `Auto 10km` | フェーズにより上記を自動で切り替える | 大会本番 |

`FLY AWAY` は「その地点から真っ直ぐ遠ざかる」モードであって、
**どこか別の点へ誘導するものではない**。

## 6. Auto 10km の状態機械

目的地は **PLATHOME を選ぶ前提**。距離は「現在地 ↔ 選択中の目的地」で測る。

```
        距離 > 10.475 km
  AWAY ──────────────────▶ INTO      AWAY: truec = 目的地方位+180（離れる）
    ▲                        │        INTO: truec = 目的地方位（戻る）
    └────────────────────────┘
        距離 < 1.5 km
```

- 判定は GNSS 更新のたびに**距離そのもの**を見る（通過を記憶するのではない）。
- しきい値は公式ルールの 10.975km / 1.0km に対し、潮流などのズレを見込んで
  それぞれ 500m 内側に取ってある。
- 切り替わると 4 音のトーンと `destination_change.wav` が鳴る。
- フェーズは SD の `auto10k_status` に保存する。**飛行中に再起動しても復路のまま復帰する**
  （距離だけでは往路と復路を区別できないため）。
- リプレイ再生中の遷移は表示だけ変え、保存値には触れない。

**このモードはパイロンへは誘導しない。** パイロンへ向かうかどうかは、
画面の基準線と TT を見てパイロットが判断する。

設定画面には歯止めがあり、`N_PILON` / `S_PILON` / `TAKESHIMA` を選んだまま
Auto 10km にしようとすると、エラー音とともに `FLY INTO` に戻される
（[../src/button.cpp](../src/button.cpp) の `is10K_NotAllowed_Destination()`）。

## 7. コース逸脱の警報

「ズレを積算して、一定量たまったら鳴らす」方式。時間で積むので GNSS が 1Hz でも 2Hz でも同じ。

```
ズレ角 steer_angle = truec − 実際の進路(TT)      （-180〜+180 に正規化）

毎回 dt 秒ぶんだけ index を増減する：
  対地速度 < 2m/s、または衛星 0      → index = 0（発動しない）
  正しい向きへ修正中                  → index −= 15 × |旋回角速度| × dt
  15°以上ズレていて修正していない      → index += min(|ズレ角|, 90) × dt
  ズレが 15°未満                      → index = 0
index は 0〜900 に飽和。900 に達したら音声（course_right / course_left）＋トーン。
発報後は 30 秒鳴らさない。
```

つまり **15° のズレを放置すると 60 秒、90° 以上なら 10 秒**で鳴る。
画面ではこの index が赤い円弧の長さになるので、鳴る前から「たまってきた」ことが見える。

## 8. 旋回角速度

直近 4 サンプルの真方位の変化量の合計を、その 4 サンプルの実経過時間で割る（`update_degpersecond()`）。
2Hz なら 1.5 秒ぶんの平均。360°またぎは ±180 に正規化する。
0.5deg/s 未満は表示しない。この値はコース警報の「修正中かどうか」の判定にも使う。

## 9. 航跡

約 50m ごとに 1 点、最大 500 点（約 25km 分）をリングバッファに保存して緑線で描く。
間隔は対地速度から決める（停止中は最大 15 秒に 1 点）。**SD には別に 2Hz で記録している**ので、
この 500 点は表示専用。

## 10. 琵琶湖コースの表示

PLA から緯度経度とも ±0.6° 以内、かつ縮尺が一定以上のときだけ描く。

- PLA → 北/南パイロンの青い基準線、PLA → 竹島の緑線
- PLA 中心の 10.975km 円と 1.0km 円
- 北/南パイロンの中間方位（**センターライン**、オレンジ）を 1km〜10.975km の間だけ
- パイロン座標から毎回計算するので、**座標を上書きすれば線も円も一緒に動く**

現在の座標での値（`navdata.h` から計算）:

| | 真方位 | PLA からの距離 |
|---|---|---|
| 北パイロン | 328° | 10.99 km |
| 南パイロン | 258° | 10.95 km |
| センターライン | 293° | － |

## 11. 保存される設定

`navigation_mode` / `destination`（名前で保存）/ `auto10k_status` / `scaleindex` / `upward_mode`。
**DEMO と REPLAY は保存しない**（電源を入れ直せば必ず本番設定に戻る）。

## 12. 既知の制約

- Auto 10km の判定距離は**選択中の目的地**から測るが、地図に描かれる 10.975km 円は
  **常に PLA 中心**。上の歯止めは 3 つの固定目的地しか見ていないので、
  `destinations.csv` で追加した地点を選ぶと両者がズレたまま飛べてしまう。
